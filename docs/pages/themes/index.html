How to Use Themes

1

Set as Default Theme

// config/flasher.php (Laravel)
return [
    'default' => 'theme.material',
];
2

Use Per-Notification

// PHP
flash()->use('theme.material')->success('Operation completed!');

// JavaScript
flasher.use('theme.material').success('Operation completed!');
